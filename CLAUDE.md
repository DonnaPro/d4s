# DonnaPro SEO — Default Settings

## Site
- Target domain: `donnapro.com`

## SEO Defaults
- Default country / market: `United Kingdom`
- Default location_name: `United Kingdom`
- Default location_code: `2826`
- Default language_name: `English`
- Default language_code: `en`

When running any SEO skill (`/seo-page`, `/seo-keywords`, `/seo-competitive`, etc.) and the user does not specify a country or location, always use **United Kingdom** (`location_code: 2826`) as the default. Do not default to United States unless the user explicitly asks for it.
